# Codex 企微审批

目标：本人任务的 Codex 审批回到原企微会话，只接受该本人回复；非本人继续使用 workspace-write + never，禁止提权。

1. 为 app-server 的命令、文件变更和临时权限请求补充回归测试，再实现独立的审批协议适配模块。
2. 增加本人任务的 app-server 执行连接，固定 on-request + user，保持联网。验证新建、续接、最终答复、取消、错误、过期审批和线程隔离。
3. 复用现有企微审批管理器和指令，更新帮助与简短文档；验证原会话、本人身份和非本人执行路径。
4. 运行全部离线测试，并使用临时目录和本机 Codex 验证协议及允许/拒绝。检查 LF 和 diff；完成代码审查。

实现决定：不能把需要企微审批的任务降级转交桌面队列。目标被占用时明确返回未投递，提示释放目标后 /retry，或 /new 后发送任务。这样审批和执行由同一连接管理。

不修改本地配置、凭据和正在运行的桥接。不在本次任务中提交或推送。
